# SYNTAX

> *"A binary should never be a black box."*

**SYNTAX** is a Reverse Engineering project focused on understanding compiled software at a low level — from executable structures and binary formats to assembly instructions, execution flow, and runtime behavior.

The project explores how software works beneath high-level abstractions, with an emphasis on **Windows binaries, low-level analysis, and reverse engineering techniques**.

---

## Focus

* **Binary Analysis** — Inspect executable structures and compiled code
* **Reverse Engineering** — Understand how software behaves internally
* **Execution Flow** — Trace functions, branches, calls, and control flow
* **Assembly** — Analyze low-level instructions and compiler output
* **Windows Internals** — Study PE files, processes, memory, and system behavior
* **Static Analysis** — Examine binaries without executing them
* **Dynamic Analysis** — Investigate runtime behavior and execution

---

## Technology

`C++` `C` `Assembly` `Windows`

---

## Philosophy

SYNTAX is built around a simple idea:

> **Compiled software is not a black box.**

Every executable contains structure, logic, and behavior that can be studied. SYNTAX aims to make that underlying complexity understandable through systematic analysis and low-level investigation.

## Scope

SYNTAX focuses on understanding and analyzing software rather than simply treating binaries as opaque executables.

```text

 ├── Calls
 ├── Memory
 └── Runtime Behavior
```
